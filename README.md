# MONSTER KART 3D 🏎️👾

An original 3D monster-kart racing game for Android, made with Godot 4.5.2.

12 playable monster karts, a colorful fantasy circuit, 7 computer racers, 3 laps, drift/boost, and touch controls.

Every push to `main` builds a signed APK using GitHub Actions secrets and publishes a single latest GitHub Release. See `.github/workflows/android.yml`.

Open `project.godot` in Godot 4.5.2 to play locally. The project generates all 3D geometry procedurally, with no paid assets.
